# Social Media Manager

AI-powered content management platform for the Emika AI Employee ecosystem.

## Features

- **Content Calendar** — Visual monthly view of scheduled posts across platforms
- **Post Creator** — Write and preview content with platform-specific character limits
- **Inspiration Feed** — Discover trending content via Apify-powered competitor scanning
- **References Library** — Save and organize content you admire
- **Scheduler** — Queue management with scheduling and recurring posts
- **Analytics** — Track engagement metrics and platform performance
- **Multi-Platform** — LinkedIn, Instagram, Facebook, TikTok, Twitter/X, Blog

## Quick Start

```bash
npm install
node server.js
```

Open http://localhost:3000

## Stack

- **Backend:** Express.js with JSON file storage
- **Frontend:** Vanilla JS SPA with dark theme UI
- **Integrations:** Apify for content scraping
